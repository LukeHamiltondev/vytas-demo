# Vytas Car Repairs: demo site

A one-page demo website for Vytas Car Repairs, a car repair garage in Ireland, built by Solaris Scaling.

Plain HTML, CSS and a little JavaScript with no build step. Open `index.html` locally, or deploy the repository root to Vercel as a static site (Framework preset: Other, no build command, output directory `.`).

## Placeholders

Anything Vytas hasn't supplied yet is shown in a dashed box (the `.ph` class): phone number, town and address, opening hours, the service list, the about text and the map. The workshop photo is a placeholder reused from the Tullamore demo. The booking form emails `bookings@example.ie`; change `BOOKING_EMAIL` in `script.js`.

## Design

The page is a workshop shadow board: a green pegboard where each service is a tool hung in its painted outline. Hovering a tool lifts it off its hook. Fonts (Big Shoulders and Archivo, both SIL Open Font License) are self-hosted in `fonts/`.
